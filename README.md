<p align="center"><strong>dsh-tolerance — 公差链与配合</strong></p>

公差链（最坏/RSS）、常用配合类型、表面粗糙度换算。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-tolerance

## 工具

- `tolerance_stack`：公差链最坏/RSS
- `fit_lookup`：配合类型查询
- `surface_finish`：工艺可达 Ra 与换算

更多工具：https://deepseekbase.com/zh/tools/
